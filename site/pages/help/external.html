Если пользуетесь несколькими устройствами — подключайте на сервере. Если не хотите отдавать пароль ящика серверу — в приложении.

Подключение в веб-кабинете

  1. Откройте {{cfg.web_url}} и войдите.
  2. Перейдите в раздел «Аккаунты».
  3. Для Gmail нажмите «Add Gmail» и войдите в Google — пароль приложения не понадобится.
  4. Для остальных ящиков нажмите «Добавить аккаунт» и укажите адрес, пароль приложения и серверы из таблицы.

Первая загрузка большого ящика занимает время — письма появляются по мере загрузки.

Подключение в приложении {{cfg.app_name}}

  1. Откройте Настройки и нажмите «Добавить учётку».
  2. Введите адрес ящика. Приложение само найдёт серверы большинства почтовых служб.
  3. Введите пароль приложения. Приложение проверит вход на IMAP и SMTP и сохранит учётную запись.
  4. Не нашлось автоматически — выберите «Я знаю все настройки» и введите параметры из таблицы.

Пароли приложений

Большинство почтовых служб не пускают сторонние программы по обычному паролю. Вместо него создаётся отдельный пароль приложения: его можно в любой момент отозвать, не меняя основной пароль.

Gmail

  1. Включите двухэтапную аутентификацию в аккаунте Google.
  2. Откройте Аккаунт Google → Безопасность → Пароли приложений, создайте пароль и скопируйте его.

Яндекс

  1. В Яндекс Почте: Настройки → Почтовые программы — разрешите доступ по протоколу IMAP.
  2. В Яндекс ID: Безопасность → Пароли приложений, создайте пароль для почты.

Mail.ru

  1. Настройки → Безопасность → Пароли для внешних приложений, создайте пароль с доступом к почте.

Названия пунктов меню у почтовых служб иногда меняются. Если не нашли — ищите в справке службы «пароль приложения».
