iPhone, iPad и Mac: профиль за один шаг

Вместо ручной настройки почты, календаря и контактов скачайте профиль — он настроит всё сразу во встроенных приложениях Apple.

  1. Откройте веб-кабинет {{cfg.web_url}} и войдите.
  2. Перейдите в Настройки → Профили устройств и нажмите «Скачать профиль».
  3. На iPhone или iPad: Настройки → Профиль загружен → Установить. На Mac: Системные настройки → Конфиденциальность и безопасность → Профили.
  4. Введите пароль, когда система попросит.

Галочка «Положить пароль в профиль» кладёт в файл пароль открытым текстом — так устроен формат профилей Apple. Такой файл не пересылайте почтой и не храните в синхронизируемых папках. Безопаснее не ставить галочку и ввести пароль при установке.

Thunderbird

  1. Учётные записи → Добавить почтовую учётную запись, введите имя, адрес и пароль.
  2. Нажмите «Настроить вручную» и укажите параметры из таблицы выше: IMAP 993 и SMTP 465, SSL/TLS, обычный пароль, имя пользователя — полный адрес.
  3. Нажмите «Готово».

Календарь: Файл → Создать → Календарь → В сети, адрес CalDAV из таблицы.

Outlook

  1. Файл → Добавить учётную запись, введите адрес, откройте «Дополнительные параметры» → «Настроить учётную запись вручную».
  2. Выберите IMAP и укажите серверы, порты и шифрование SSL/TLS из таблицы.
  3. Введите пароль и завершите настройку.

Другие приложения на Android

В любом почтовом приложении выберите тип учётной записи IMAP («Другая почта», «Личная (IMAP)») и введите параметры из таблицы. Для мгновенных уведомлений и бесед используйте {{cfg.app_name}}: сторонние приложения проверяют почту по своему расписанию.
