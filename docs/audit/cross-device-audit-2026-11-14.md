Один набор сценариев (1–11) на четырёх устройствах: что расходится с десктопом и что сломано. Код не правился.

Эталон, по убыванию силы: `docs/mobile-layout.md` → `docs/desktop-behavior-contract.md` → платформенные
`docs/android-behavior-contract.md`, `docs/ios-behavior-contract.md` → `docs/mobile-external-accounts.md`.
Каждая находка сверена с абзацем контракта и цитирует его. Где контракт молчит, так и написано.

## Что проверено без расхождений

- **Android (сложен; разложен — эмуляция):**
  - **Компоновка:** первая строка — бургер + поиск, табы папок. Нет FAB, «⋯», заголовка, нижней панели и rail'а. Бургер: Почта / Календарь / Контакты / Задачи / Настройки.
  - **«Спам»:** скрыт; «Показать скрытые (2)» показывает его бледным табом, в меню его таба нет «Настроить…» и «Удалить».
  - **Папки:** создание (сразу в настройки), переименование, скрыть / показать, удаление с подтверждением — диалоги вернулись во «Входящие». «В папку» показывает скрытые папки и не показывает «Спам». Папки синхронизируются между устройствами: папка, созданная на iOS, появилась на Android.
  - **Поиск:** секции «Написать по адресу» / «Диалоги» / …, новая беседа с пустой лентой.
  - **Лента:**
    - меню пузыря у пузыря; «Показать… → Заголовки / Исходник сообщения / Исходник тела (HTML) / Текстовую версию»;
    - двойной тап выделяет слово, тройной — фразу;
    - меню вложения: «Открыть / Поделиться / В «Загрузки»».
  - **Композер:** «Ж» через меню выделения, От / Кому / Копия / Тема, вложение файла. Отправка в существующей беседе: «Отправляется…» → «✓ Отправлено». Ошибка доставки — отметка «Не доставлено» в строке.
  - **IMAP-учётка:** общий список, отправка через SMTP Mail.ru, письмо доставлено на info@.
  - **Календарь:**
    - сложен: лента дня и лента месяцев;
    - разложен: «Год / Месяц / Неделя / День» по убыванию охвата, «ещё N» видна, тап по ней открывает день;
    - создать, изменить, перетащить на час, удалить.
  - **Контакты:** список, поиск, создать с двумя адресами и двумя телефонами (на сервере ровно так), изменить, удалить. У «Shared» — «Только чтение».
  - **Задачи:** создать, выполнить, «Показать выполненные», удалить.
  - **Настройки:** учётки, удалить учётку Mail.ru и добавить заново (автопоиск сервера, пароль приложения). Отдельного «Выйти» нет — у десктопа его тоже нет.
  - **Тема:** при системной тёмной приложение остаётся светлым.
  - **Разложен:** колонка списка и беседа справа.
- **iPhone, iPad** (подробно — в отчёте форка, сведено сюда):
  - **Компоновка и «Спам»:** как у Android; меню строки «Спама» — «Не спам» / «Не спам и доверять отправителю».
  - **Папки** — полный цикл.
  - **Поиск** — «Написать по адресу» первой строкой.
  - **Лента:** меню пузыря, «Показать…», двойной и тройной тап, вложение в QuickLook, меню «Открыть / Поделиться / Сохранить в «Файлы»».
  - **Композер:** «✓ Отправлено» через ~1 с, беседа через ~3 с. Ошибка доставки — красная плашка, отметка в строке, письмо-отказ (DSN).
  - **Календарь:** создать / изменить / удалить; на iPad — «Год / Месяц / Неделя / День».
  - **Задачи** — полный цикл.
  - **Настройки:** учётки, «Войти заново», «Добавить учётку». Удаление последней учётки ведёт на «Подключение».
  - **Тема:** при системной тёмной всё светлое.
- **Нет «Скрытой» (Bcc) в композере** — на всех устройствах. Это не расхождение: десктоп её не умеет (desktop §1: «`mailto: скрытая копия не поддерживается`», §4 «Bcc в набор не входит»).
