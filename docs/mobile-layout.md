# Компоновка мобильных клиентов = компоновка десктопа

Решение владельца 2026-11-13: **решение, которое отличается компоновкой от десктопа, неприемлемо — так
должно быть везде** (Android, iPhone, iPad, Mac). Источник — `desktop/native/ui/app.slint`
(сайдбар почты, меню-бургер `view-menu-open`) и `desktop-behavior-contract.md` §4 «Поиск», «Папки
диалогов». Платформенные контракты (`android-behavior-contract.md` §6/§16, `ios-behavior-contract.md`
§6/§9) этому документу подчиняются; где они расходятся — прав этот документ.

## Левая колонка почты (на телефоне — весь экран списка)

Сверху вниз, ничего больше:

1. **Строка: бургер + поле поиска.** Бургер (три полоски, иконка платформы) слева, справа от него —
   круглое поле поиска на всю оставшуюся ширину. Это первая строка экрана: над ней нет заголовка
   «Почта», подписи учётки, кнопок тулбара.
2. **Полоса табов папок диалогов** (как у десктопа: текст, выбранный — зелёный с подчёркиванием,
   «← Входящие» со счётчиком, пока выбрана папка; системная папка **«Спам»** — таб этой полосы, а не
   пункт меню). Папок нет — полосы нет.
3. **Диалоги.**

**Нет и не будет:** кнопки «Написать»/FAB/карандаша, меню «три точки», пункта «Спам» в меню,
заголовка раздела над списком, нижней панели вкладок (tab bar), бокового rail'а разделов, боковой
колонки разделов iPad/Mac (sidebar `TabView`).

## Бургер

Меню-оверлей, пункты как у десктопа, по порядку: **Почта, Календарь, Контакты, Задачи, Настройки**.
Выбранный раздел отмечен. Это единственная навигация между разделами. «Добавить учётку», состояние
учёток, загрузка заранее и т.п. — в «Настройках».

Бургер — в левом верхнем углу **каждого** раздела, в его первой строке:
- Календарь — бургер + навигация по датам (‹ Сегодня ›) + заголовок периода + «Новое событие»;
- Контакты — бургер + «Контакты» + «+»; ниже поле «Поиск контактов», ниже список;
- Задачи — бургер + «Задачи» + переключатель «Показать выполненные».

## Новое письмо

Только через поиск, как у десктопа: ввели в поле адрес — первая строка выпадашки «Написать по
адресу …» открывает новую беседу с этим адресатом (композер внизу пустой ленты). Секции выпадашки
по порядку: «Написать по адресу…», «Диалоги», «Контакты», «Сообщения». Пересылка и ответ — как
раньше, из беседы.

## Правая часть

Открытая беседа (широкий экран — справа от колонки, узкий — поверх списка) — без изменений.
