# RuStore: карточка приложения и политика конфиденциальности

Черновик для публикации Android-клиента в RuStore (решение 2026-11-12). Тексты
карточки и политики — на вычитку владельцу: политика — юридическое заявление
оператора персональных данных, её содержание решает он.

## Сборка

- Вариант `rustore` (обычные Android-телефоны, RuStore Push; до 0.0.38 назывался `gms`),
  релиз: `./gradlew assembleRustoreRelease`
  → `~/.cache/builds/gradle/ddmail-android/app/outputs/apk/rustore/release/app-rustore-release.apk`.
- Push: проект в RuStore Консоли («Push-уведомления» → «Проекты»), его ID — в
  `~/.config/ddmail-android/rustore.properties` (`project_id=…`) станции сборки,
  ID и сервисный токен — в `push.rustore` конфига сервера (android-behavior-contract §7).
- Пакет `ru.letotam.ddmail`; подпись — постоянный ключ `~/.config/ddmail-android/release.jks`
  (сертификат SHA-256 `5307940420de9fb5f70444c4e1583394bb899828f81747e492cf7238fe0b17f5`).
  **Потеря ключа = невозможность выпускать обновления под тем же приложением**:
  держать резервную копию вне станций.
- Версия — `versionName`/`versionCode` в `app/build.gradle.kts`; каждая выкладка — новая версия.

## Карточка

**Название:** ddmail

**Краткое описание** (до ~80 знаков):
Почта, календарь и контакты с вашего сервера ddmail — в одном приложении.

**Полное описание:**

ddmail — клиент для собственного почтового сервера ddmail. Все ваши ящики, собранные
сервером, — в одном месте, в виде переписок, а не плоского списка писем.

• Беседы вместо писем: переписка с человеком — одна лента, как в мессенджере.
• Папки диалогов с правилами — те же, что на компьютере.
• Цвет беседы по адресу, на который пришло письмо: рабочее и личное видно сразу.
• Спам не беспокоит: отдельная папка без уведомлений и без загрузки картинок.
• Картинки из писем не грузятся без вашего разрешения — трекеры не узнают, что вы открыли письмо.
• Календарь, напоминания о встречах, задачи и контакты с того же сервера.
• Работает и на складных телефонах: в разложенном виде список и беседа рядом.

Для работы нужен сервер ddmail. Пароль не хранится на телефоне — только токен сессии.

**Категория:** Бизнес → Почта (или «Инструменты», если «Почты» нет).
**Возраст:** 0+ (контента нет, только почта пользователя).
**Сайт:** https://mail.letotam.ru/ · **поддержка:** legal@mfml.ru
**Политика конфиденциальности:** https://mail.letotam.ru/privacy (исходник — `deployments/privacy.html`, выкладка 2026-11-12: `/var/www/html/privacy.html`, nginx `location = /privacy` в `mail.letotam.ru`).

**Скриншоты:** 3–5 с телефона (список бесед, беседа, календарь, контакты). Снимать на
Mate XT в сложенном виде (`adb.exe exec-out screencap -p`); данные — тестовой учётки,
без чужих адресов и тем писем (152-ФЗ: на скриншотах — персональные данные корреспондентов).
